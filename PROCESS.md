# Process archive

This root-level document preserves the prompts and production briefs used to develop the album. The source archive contains local candidate MP3s; those files are intentionally omitted from this public package. Canonical listening is provided through the links in `TRACKLIST.md`.

Some briefs describe workshop tracks that are outside the twelve-track sequence. They remain here because the experiments are part of the engineering record.

## Publication gate

Before adding material to the public canon, check:

- [ ] The file contains no private filesystem paths, credentials, or personal information.
- [ ] Canonical recordings are separated from workshop candidates.
- [ ] Generated-audio, artwork, lyric, and external-platform provenance is stated where relevant.
- [ ] Safety language is clearly fictional satire, not operational guidance.
- [ ] Rights and reuse boundaries are consistent with `LICENSE.md`.
